Sistem berbasis LLM multi-agent yang membaca laporan Cyber Threat Intelligence (CTI) lalu memetakan secara otomatis ke Tactics dan Techniques MITRE ATT&CK — lengkap dengan validasi analis dan ekspor STIX 2.1 serta laporan PDF.

▷ Mulai Analisis Lihat Cara Kerja

Apa yang dilakukan tools ini?

Mengubah laporan CTI naratif menjadi pemetaan TTP terstruktur secara otomatis.

🤖

Multi-Agent LLM

Agen Taktik & agen Teknik bekerja terpisah, lalu agen Reviewer mengkritik dan memicu revisi (debat antar-LLM) untuk hasil lebih akurat.

🔍

RAG ATT&CK

Retrieval kandidat teknik dari basis pengetahuan MITRE ATT&CK Enterprise (738 teknik) agar LLM memilih dari daftar yang relevan.

✅

Validasi Analis

Hasil pemetaan dapat divalidasi (terima/tolak) oleh analis sebelum difinalisasi — human-in-the-loop.

📤

Ekspor STIX & PDF

Keluaran ganda: bundle STIX 2.1 (machine-readable) dan laporan PDF rapi untuk dokumentasi.

💻

LLM Lokal

Berjalan di atas model lokal via LM Studio (Qwen3) — data tidak keluar ke layanan pihak ketiga.

📄

Multi-Format Input

Mendukung teks tempel, file .txt, .json/.mjson (TRAM II), dan .pdf.

Cara Kerja

Pipeline orkestrasi LangGraph dari input hingga keluaran.

01

Input

Unggah / tempel laporan CTI. Teks diekstrak (termasuk dari PDF).

02

Tactic Agent

LLM mengidentifikasi taktik ATT&CK dari narasi.

03

Technique Agent

Retrieval kandidat → LLM memilih teknik yang relevan.

04

Review & Reconcile

Reviewer mengkritik, sistem merevisi & menyaring konsistensi.

05

Output

STIX 2.1 bundle + laporan PDF siap diunduh.
